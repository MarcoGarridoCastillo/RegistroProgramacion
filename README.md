
Mi primer proyecto en C# como parte de mi proceso de aprendizaje
y desarrollo profesional.

## Objetivo

Practicar los fundamentos de C# y aprender a utilizar Git y GitHub
para registrar y documentar la evolución de mis proyectos.

## Tecnologías

- C#
- .NET 10
- Git
- GitHub
- Visual Studio Code

## Funcionalidad actual

- Mostrar información de una sesión de estudio.
- Ejecutar una aplicación de consola.
- Practicar la estructura básica de un programa en C#.

## Cómo ejecutar el proyecto

1. Instala el SDK de .NET 10.
2. Clona este repositorio.
3. Abre una terminal en la carpeta del proyecto.
4. Ejecuta:

   dotnet run
